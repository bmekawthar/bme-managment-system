A web-based hospital equipment management system designed to organize medical equipment, departments, inventory, and maintenance activities.

- ## Features

- **Equipment Management:** Manage medical equipment information, specifications, status, and location.
- **Department Management:** Organize hospital departments and their assigned equipment.
- **Inventory Management:** Track inventory items, quantities, and stock levels.
- **Preventive Maintenance (PM):** Schedule maintenance activities, monitor due dates, and maintain maintenance records.
- **Corrective Maintenance (CM):** Report equipment faults, monitor repair progress, and document repair activities.
- **Equipment Transfers:** Track equipment movements between hospital departments.
- **Flagged Equipment:** Mark and access important equipment for quick reference.
- **Statistics :** Monitor equipment statistics .

## Installation

### Prerequisites

- Node.js
- npm

### Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/bmekawthar/bme-managment-system.git
   ```

2. Navigate to the project directory:

   ```bash
   cd bme-managment-system
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

## Usage

The BME Management System provides an intuitive interface for managing biomedical equipment and related activities.

Users can navigate through the different sections, interact with dedicated forms, access stored information, and monitor ongoing operations through an organized workflow.

## Technologies

- **React** – Building the user interface.
- **JavaScript** – Application logic and functionality.
- **CSS** – Styling and layout.
- **React Router** – Navigation between pages.
- **Vite** – Development server and build tool.
- **Local Storage** – Storing application data in the browser.
- **date-fns** – Date formatting and calculations.
- **React Day Picker** – Date selection and calendar functionality.
